FLAGSHIP STARTUP Commerce · Fintech · Infrastructure

Shopswift

Shopswift is a QR-powered commerce platform connecting physical retail with digital payments. It enables shoppers to scan products, build baskets and pay digitally, while giving merchants tools for checkout management, payment processing and transaction reconciliation.

MY ROLE

Founder, Technical Lead & Full-Stack Developer

I lead the technical development and operation of Shopswift, taking responsibility for its application architecture, backend infrastructure, payment systems and security.

Infrastructure & Backend Engineering

  • Provisioned and managed Linux-based server infrastructure using Ubuntu.
  • Configured and maintained Node.js application environments, PostgreSQL databases and PM2 process management.
  • Managed production deployments, environment configurations and application troubleshooting.
  • Worked on backend architecture, API integrations and database operations.
  • Configured DNS and the domain for shopswiftpay.com, including SSL/TLS certificates.
  • Set up company email on the shopswiftpay.com domain, including MX, SPF and DKIM records.
  • Secured server access with SSH keys and firewall rules.
  • Set up PostgreSQL database backups.

Payment Infrastructure & Integrations

  • Integrated third-party payment services and developed payment collection workflows.
  • Worked on checkout-specific virtual accounts (DVAs) to support payment identification and automated transaction verification.
  • Developed merchant settlement workflows designed to route payments directly to merchants' bank accounts.
  • Implemented feature-controlled payment integrations to support staged testing and deployment.

Application Security & Reliability

  • Worked on authentication, session management and credential security.
  • Reviewed secret and encryption-key management, including production configuration safeguards.
  • Implemented security remediation covering authentication, session handling and payment-related workflows.
  • Reviewed QR token validation and invalidation to strengthen checkout integrity.
  • Expanded automated test coverage to validate payment integration and security-related changes.
